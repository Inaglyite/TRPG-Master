## 明确限制

1. 这是人类主持工具链验收；未调用付费模型，Agent 全主线未验证。共享规则真实模型主线须本轮独立授权。
2. 旧作者未给物品—使用规则绑定；人类负责选择适用规则并写依据，平台只核验已声明条件/来源/持有/检定。Agent 不获这种覆盖权。
3. 发现命令不代结算 SAN、战斗或结局；人类主持须使用相应显式工具。没有把作者 SAN 提示当成已扣除。
4. 旧未关联库存只在显式取得/唯一同名核对时登记来源，不根据叙事或标签子串自动赋予原件权限。
5. 不新增或改写作者时钟。`clue_clarity` 延续既有作者线索首次入册约定；未声明时钟的模组不凭空创建。
6. 本轮不改变此前登记的整体静态刷新覆盖自定义场景目录、普通骰单进程限频等边界。
7. 本检查点之后的隔离探针曾发现NPC库存候选缺失及非法接收者可转交，反例
   `transfer-holder-audit.log`保留。后续88021898已补真实持有者/物品候选、存在性核验、
   来源保留与秘密隔离，真实调查员→NPC→场景→调查员环路已通过；准确证据见顶部链接。
