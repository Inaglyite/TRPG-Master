## 2. 最近进入源码的功能与修复

### 开始页、模组管理与游戏设置

- 开始页辅助入口集中在右上角一排透明 PNG 小图标。导入、工坊、管理、角色库与设置可悬停查看名称；桌面客户端另有退出入口。修复导入入口悬停时图案消失的问题。
- 本地“模组管理”列出安装版本、时间线与存档数量。确认删除导入版本时，一并永久删除该版本的世界、已归档分支、自动/手动存档和回合历史；角色库、工坊工程及其他版本保留。内置或正在使用的版本拒绝删除。重新导入不会恢复已删进度，详见[作者入口](MODULE_FORMAT.md#删除并重新导入)。
- “模型设置”扩展为“游戏设置”，含游戏偏好、模型配置和上下文页。“显示行动提示”默认开启；关闭后隐藏正文“你可以——”和底部建议，保留自由输入与必要确认/检定。偏好立即生效并保存在本机，不改写存档或模型输出。

### 对话契约与人物身份

- 新生成的 `dialogue_v1` 只在顶层 `choices` 放行动选项；正文夹带菜单或选项格式错误会在发布前拒绝。格式修复最多一次，禁用游戏工具，再次失败不发布可疑回复。旧历史保留兼容读取，不批量重写存档。
- 新出现且已公开姓名的人物可登记为本场景的 `guest_speakers` 展示身份，并参与本轮介绍/发言校验；这不自动创建作者态正式 NPC、解锁线索或获得任意 NPC 工具权限。
- 修复稿复用较长台词却改换人物 ID 时以 `speaker_reassigned` 拒绝，避免把新人物台词交给其他在场人物。短句与任意语义串人仍不由这一项检测完整覆盖。
- 旁白中的成段台词另有有界归属复核；气泡按稳定 ID 和公开姓名匹配，头像缺失以首字徽章兜底。旧错误台词不因升级自动纠正。

契约和边界见[协议](PROTOCOL.md#ai-对话出发待决与状态修正)。

### 可追溯的日志

后端提供 `trpg.log` 与轮转 `diagnostics.jsonl`。诊断可关联回合、模型/重试、工具结果，以及原始/拒绝/接受/回调/提交正文；`output_id` 区分不同模型输出尝试。
`tools/diagnose_turn.py` 支持列出历史回合、按截图文字搜索和按世界/回合过滤，覆盖所有仍保留的轮转文件。
日志不会补录升级前的对话，也不是数据库永久历史；回调完成不等于浏览器已渲染。
正文证据可能含剧情与个人信息，默认保存但查询时隐藏，可独立关闭。目录和命令见[日志排障](DEVELOPMENT.md#按回合查看开发日志)。

### 模型接入、终端与正文排版

- 厂商预设与 Chat Completions / Anthropic Messages / Responses 接口格式分别选择，叙事、裁决、摘要、复核和线索整理共用传输边界。流式连接测试与裁决工具探针实际执行；模型列表仅作可选候选来源。
- CLI 支持失败后 `/retry`、无模型读档、`/save-new` 独立槽位和虚拟环境/模型路由兼容。启动发现存档时先等 `/load` 或 `/new`，不先重置世界。
- JSON 正文保留 Markdown 标题和强调；一致性辅助校对有独立 20 秒超时和零自动重试，失败保留原文继续提交。阶段提示区分生成、核对与持久保存；未提交回合不冒充完整存档。

具体操作见[开发说明](DEVELOPMENT.md)，各厂商真实 API 与旧阶段模型证据见[历史验收](INDEX.md#归档资料)，不声称所有预设都做过逐家真实服务验收。

## 4. 保留的限制与技术债

| 范围 | 边界 / 后续要求 |
| --- | --- |
| structured Agent | 真实模型的新命令域完整主线需独立验收，不能由 human 或 legacy 通过替代 |
| 自然语言秘密隔离 | 早期公开回复曾复述私有计划含义，尚未取得完整关闭证据；权限/事件过滤或字面断言通过不能证明任意叙事绝无泄密 |
| 限流与扩容 | 普通骰为账号级单进程限频，重启清空；其他入口预算分别核对，多 worker/多节点需共享所有权与限流后端 |
| 主持兼玩家 | 同一身份有主持权限就能看到秘密，视角切换不构成知识隔离 |
| 多人恢复 | 单人读档/分支通过不等于多人任意读档、分队或开场调度均已覆盖 |
| 恢复语义 | 主动读档使未完成请求 reconcile/failed、检定授权作废；不是原样续接模型调用，普通重连不触发此清理 |
| 叙事一致性 | 权威状态由工具提交；提示词、格式和局部人物检查不保证叙事永不矛盾，过渡待办不是执行授权 |
| 旧模组迁移 | supersedes 只保护精确匹配路径；整体静态刷新仍可能覆盖世界内自定义 scene_catalog |
| legacy 调查停滞 | 历史 R1 异地监视拒行、R2 复制件停滞未取得逐项关闭证据，不能以另一轮主线通过推定关闭 |
| 安全与备份 | 旧安全报告须逐项关联当前实现；曾外发凭据需要确认轮换；本机 mid_product 不是独立备份，原始轨迹不直接公开 |
| 工坊独立更新 | 旧客户端须先升级取得组件更新机制；兼容性、用户确认、校验失败回退与云端部署边界仍适用 |

已探索地点的移动图已实现；可自由布置的场景地图、Token、迷雾、自由分队、多节点、更多规则、模组创作助手、公告与后台管理仍是候选方向。
