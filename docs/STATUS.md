## 保留的限制与技术债

| 范围 | 当前边界 / 下一步 |
| --- | --- |
| structured 完整性 | 暂无战斗、结局命令域；调查/社交专项通过不是完整主线通过。本地结构化创建入口及模型配置解析仍有缺口 |
| 结构化限流 | `rate_limited` 分支仍有未实现登记；核对命令、记忆查询与模型调度的频率/预算控制。不是声称整个应用没有限流 |
| 主持兼玩家 | 同一身份拥有主持权限时本来就能看到秘密；不能承诺视角切换能让该人“忘记秘密”。普通玩家帧级隔离仍必须成立 |
| 多人读档与开场 | 单人分支通过不代表多人房间读档通过；自动开场与首次玩家请求的依赖也需单列产品验收 |
| 恢复语义 | 读档对未完成请求做 failed/reconcile，pending 检定作废；不是原封不动续接模型调用。普通重连不应触发这套清理 |
| 叙事一致性 | 工具提交决定状态；提示词和局部时间模式核对不保证所有叙事都不矛盾。过渡待办是记忆，不是执行授权 |
| 旧模组迁移 | supersedes 只保护精确匹配升级路径；版本变化时整体静态刷新仍可能覆盖自定义 scene_catalog |
| legacy 调查停滞 | R1 处所式异地监视拒行、R2 复制件停滞曾登记；不能用另一条主线通过推定已关闭。见[收口记录](archive/2026-09/reports/ADVISORY_TRANSITION_FINAL_CHECKS_20260913.md) |
| 安全收口 | 旧安全报告是当时发现，不是现存漏洞清单。应逐项关联当前实现与验收，确认曾外发凭据轮换，不在文档记录秘密值 |

结构化后端原始边界见[后端验收](archive/2026-09/reports/STRUCTURED_PLAY_BACKEND_ACCEPTANCE_20260914.md)，安全历史见[调查记录](archive/2026-09/investigations/SECURITY_REVIEW_AND_HARDENING_PLAN.md)。后续修复要以新证据更新本页，不能只修改历史报告的结论。
