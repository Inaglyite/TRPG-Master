## 保留的限制与技术债

| 范围 | 边界 / 后续要求 |
| --- | --- |
| structured Agent | 真实模型的新命令域完整主线需独立验收，不能由 human 或 legacy 通过替代 |
| 限流与扩容 | 普通骰为账号级单进程限频，重启清空；其他入口预算须分别核对，多 worker/多节点需共享所有权与限流后端 |
| 主持兼玩家 | 同一身份有主持权限就能看到秘密，视角切换不构成知识隔离 |
| 多人恢复 | 单人读档/分支通过不等于多人任意读档、分队或开场调度均已覆盖 |
| 恢复语义 | 主动读档使未完成请求 reconcile/failed、检定授权作废；不是原样续接模型调用，普通重连不应触发此清理 |
| 叙事一致性 | 权威状态由工具提交；提示词与局部模式检查不保证叙事永不矛盾，过渡待办不是执行授权 |
| 旧模组迁移 | supersedes 只保护精确匹配路径；整体静态刷新仍可能覆盖世界内自定义 scene_catalog |
| legacy 调查停滞 | 历史 R1 异地监视拒行、R2 复制件停滞未取得逐项关闭证据，不能以另一轮主线通过推定关闭 |
| 安全与备份 | 旧安全报告须逐项关联当前实现；曾外发凭据需要确认轮换。本机 mid_product 不是独立备份，不应直接公开原始轨迹 |

地图/Token/迷雾、分队、多节点、更多规则、模组创作助手、公告与后台管理仍是候选方向，不是本版本已承诺能力。
