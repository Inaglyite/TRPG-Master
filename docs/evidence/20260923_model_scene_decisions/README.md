# 模型决定场景切换：医学院固定过场修复

截图输入是“我想看看莱特教授的尸体”，输出却声称玩家说了“医学院”。
医学院停尸房是模组中的遗体所在地；这句错误的玩家引语来自
`mod/猩红文档/world_state_initial.json` 的 `wright_body_handoff.transition_text`。

原链路先匹配 `discovery_target` 路线，再交给模型裁决；模型选择相同目的地时，
裁决器仍继承旧路线，回合准备直接播放 `action_advisories`、赶路与 `entry_beat`。
后者还会作为权威叙事事实注入模型，造成固定过场与实际玩家输入不符。

修复后的默认模型路径：

- 模型读取当前状态、最近对话与候选地点设定，自行决定停留交流或移动。
  不再注入规则解析选定的 `deterministic_hint` 和可执行过场脚本。
- 移动裁决记录 `destination_reason`。语义理由由模型判断；代码校验地点存在、
  前置条件、角色行动能力、战斗状态、时间与效果边界。
- 模型移动使用新的 `model_adjudicated` 结算，不继承旧路线的台词和预演卡。
  叙事模型根据已结算的起终点自然交代目的地来源、行程和抵达。
- 裁决失败时，即使旧匹配器识别出地点，也不自动移动。
- 无模型/显式关闭裁决的旧模式仍保留原运行方式；旧冻结提案缺少语义理由时，
  保留目的地兼容校验。本次没有删除离线规则系统，也没有改结构化多人主持路径。

验证均在本地临时 runtime 的新世界进行，没有访问或修改正式环境。

自动化回归：221 passed，10 subtests passed。覆盖场景决策、发现、预演、骰前裁决、
目的地、回合结算、结果边界、场景投影和 handout；Ruff 与 diff 空白检查通过。

[focused_probe.json](focused_probe.json) 保存真实模型的四轮完整叙事：

1. 截图原话：模型决定前往医学院，叙事先由法伦交代停尸房位置，再描写行程；
   没有“听你说出医学院”或自动电话安排。
2. 只询问遗体位置、明确暂时不走：留在办公室。
3. 承接上轮“那就去那里，出发吧”：抵达医学院。
4. 请法伦联系医生、明确不出发：仍在办公室。

[semantic_probe.json](semantic_probe.json) 保存另外四组真实裁决，全部符合预期：
医生说“我的办公室”不误跳莱特办公室；回去找已知医生能选择医学院；
取消前往与假设讨论均不移动。
