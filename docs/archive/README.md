# 历史归档索引

整理日期：2026-09-16。这里保存当时的计划、事故调查和交付记录；它们不是当前执行授权，也不能替代[现行状态](../STATUS.md)。主入口见[项目 README](../../README.md)。

## 保留规则

- 正文与原始结论保留，迁移只增加范围提示、修正导航；历史矛盾由 STATUS 解释，不改写成已经完成。
- 按月份与用途归档：plans / investigations / reports。文件日期不明的旧路线图按内容所属阶段放入 2026-08。
- `docs/evidence/`、`docs/screenshots/` 不搬迁；`/tmp` 证据可能已经失效，不能凭路径存在于报告就称证据可用。
- 新过程报告直接进入对应归档目录；先将未完成事项与验收结论同步到 STATUS。不要删除尚未结案的证据。
