# 调查员三卡片 UI：可复制生成提示词

日期：2026-09-07。配套实施计划：[INVESTIGATOR_PANEL_REFACTOR_PLAN.md](./INVESTIGATOR_PANEL_REFACTOR_PLAN.md)。

## 1. 使用顺序

1. 先生成 **A：整体效果图**，用来确认风格和布局，不直接作为游戏界面背景。
2. 确认方向后，生成 **B：无字卡片底板** 与 **C：三张独立卡片徽记**。每张素材单独生成，不生成需要人工拆分的九宫格。
3. **D：按钮底板可选**。现有 `cta_button_brass.webp` 和 CSS 已可承载按钮，不必重新生成。
4. **E：窄屏效果图可选**，用于检查抽屉形态；真实尺寸验收仍以代码截图为准。

风格参考建议附上你自己的游戏截图（包含顶部金属图标与聊天气泡）或仓库 `docs/screenshots/character-panel.png`。截图只约束材质和颜色，旧面板的混排结构不再沿用。若生成工具支持参考图强度，保持适中，避免把旧布局一起复制。

不需要新人物头像、线索插画或物品插画：沿用已有角色和模组素材，防止 UI 装饰泄漏剧情。展开箭头、关闭、详情、搜索等功能图标直接用代码/SVG，保持小尺寸清楚。

## 2. 全部素材共用的约束

- 1920 年代新英格兰调查档案；深棕黑、旧黄铜、低对比纤维质感；克制，不采用赛博霓虹、现代应用看板或中世纪厚重装备框。
- 核心颜色：`#14100c`、`#1e1812`、`#3a2f24`、`#c8a24e`、`#ddd0bc`。
- 装饰只在边缘和小徽记处；中心内容区至少 85% 干净。图形不得穿进正文和按钮命中区。
- 效果图允许中文示意文字；**生产素材不含任何文字、字母、数字、进度条、按钮标签或水印**。
- 生产素材正视、平面、正交，没有倾斜透视和摄影桌面背景。
- 请求透明背景时必须交付真实 alpha，不能把棋盘格画在图里。工具不支持透明导出时标为待抠图，不冒充透明素材。
- 输出尺寸是目标规格；工具不支持精确尺寸时按同宽高比生成，再等比处理，禁止把边框粗暴拉伸。
- 原始输出 PNG 保留；接入时可转换 WebP，需保留 alpha。透明边缘不能出现白边、黑底矩形或裁切的装饰。

## A. 整体桌面效果图（布局参考，不是可切片生产资产）

建议尺寸：1600×1000，或相近 16:10 横图。附现有游戏截图作为风格参考，复制以下完整提示词：

```text
请为一个中文、1920年代新英格兰背景、克苏鲁调查题材的 LLM 驱动叙事游戏，设计一张高保真的桌面游戏界面效果图。参考我附上的现有游戏截图，保留原有深棕黑背景、旧黄铜图标、暖灰中文正文和守秘人聊天气泡风格，只重点重构右侧调查员侧栏。不是现代 SaaS 看板，也不是手机抽卡游戏。

画布为16:10横图，正面平面UI，没有显示器外壳，没有桌面道具背景。顶部保留一条克制的现有工具栏。左侧约76%的区域是聊天叙事与底部行动输入，右侧约24%是竖向侧栏。聊天区域仍然是视觉主角。

右侧必须是三张分离但同一套风格的卡片，从上到下依次为：
1）“人物状态”：小头像占位、姓名“黄千陆”、职业“调查员”，清楚显示“HP 8/10”和“SAN 52/60”，细进度条，有“详细属性”展开入口，卡片头有收起控件。不要占满侧栏高度。
2）“线索”：标题旁显示数量，下面是“全部 / 探案 / 事件 / 任务 / 人物”的紧凑分类筛选；分组可展开收起。画出一条“莱特的日记”和一条“目击者口供”，每条有小型详情展开控件和右侧文字按钮“出示”。只有一条详情展开，其余是短摘要，不能把所有正文全摊开。
3）“道具”：展示“银质徽章”“手电筒”“绷带（2份）”，每一行右侧都有明确文字按钮“使用”。不要出现重量、装备槽、稀有度星级或未要求的数据。

三张卡片有12像素左右呼吸间距，低对比暗色纸纤维底，旧黄铜细边，只在左上角做很小的档案徽记：人物用身份档案夹、线索用证据纸页、道具用皮革工具包。三卡片边框不超过卡片视觉面积的10%，中心内容干净易读，不要大块浮雕遮挡文字。

色彩约束：背景#14100c，卡片#1e1812，边框#3a2f24，黄铜#c8a24e，正文#ddd0bc。标题为克制的中文宋体感，正文清楚，数字为打字机感。红色和蓝色只用于HP与SAN，不要到处发光。

所有“出示”“使用”按钮大小一致、文字完整横排、四周有明显内边距。长线索名可以换行，但按钮不能被压扁。整体应像在游戏里使用一套便携调查档案，而不是浏览表格后台。生成一张完整效果图，不要拼贴多个候选方案，不要水印。
```

说明：效果图里的示例不代表开局已获得这些物品。实施和真实游戏只能显示服务器当前已知/持有的数据。生成模型写错中文不意味着要照抄，正式文字由代码渲染。

## B. 通用无字卡片底板（优先生成）

建议文件名：`investigator_card_surface.png`。尺寸：1024×1024。实际卡片高度由 DOM 内容决定；这张底板必须支持九宫格边框或独立边角复用，不能将整图任意拉成长条。

```text
生成一个可直接用于游戏UI的“调查档案卡片底板”，单张资产，1024×1024正方形，正面正交平面视角。1920年代新英格兰神秘调查档案的材质，适配深棕黑与旧黄铜游戏界面。

卡片主体是极深棕色#1e1812，内部只有几乎不可见的细纸纤维和皮革压纹。四周是一圈很细、克制、略有氧化的旧黄铜边框#c8a24e，亮度降低，不发光。四角只有微小的金属包角；边缘磨损很轻，不能像废墟或烧焦羊皮纸。

为网页九宫格拉伸而设计：四个角的装饰完全限制在画布四角各64×64像素内；中间直边完全平直、材质连续、没有文字铭牌、没有中央徽章、没有横跨卡片的纹样。主体中央至少85%的区域干净均匀，适合覆盖密集但易读的中文文字。

外轮廓完整，四周留16像素透明安全边距；卡片内部为不透明深棕色，外部为真实透明alpha。不要投射到卡片以外的大阴影，不要斜透视，不要桌面背景，不要立体书本。不要文字、数字、图标、进度条、头像、按钮、烫金标题、五芒星、骷髅、触手、水印或棋盘格背景。

只输出这一张无字卡片底板，不输出展示样机或多个变化版本。
```

接入备注：64px 是生成目标，不是可盲用的 CSS slice 参数；收到图片后测量真实边角与透明边界。若九宫格效果不稳定，只取低对比内纹理，以 CSS border + 小装饰角实现卡片，不以素材为由锁死卡片高度。

## 3. 给实施者的素材交付合同

建议最终放在 `frontend/src/assets/ui/investigator/`，通过现有构建 import 处理，不硬编码不存在的绝对 URL。

| 资产 | 优先级 | 用途 |
| --- | --- | --- |
| `investigator_card_surface.webp` | 推荐 | 三卡片共用边框/低对比纹理；可以纯 CSS 降级 |
| `investigator_status_emblem.webp` | 可选 | 人物卡标题小徽记 |
| `investigator_clues_emblem.webp` | 可选 | 线索卡标题小徽记 |
| `investigator_items_emblem.webp` | 可选 | 道具卡标题小徽记 |
| `investigator_action_button.webp` | 可选 | 出示与使用共用底板；优先复用现有按钮主题 |

建议压缩预算：底板≤200KB，单徽记≤60KB，按钮≤80KB；以可读性、alpha 正确、无白边优先，预算是目标不是盲目损坏图像的硬要求。原图不进入热路径。

接入前检查：真实透明、边界完整、文字区干净、28px 徽记仍可辨认、低亮度屏幕按钮可见、长卡片拉伸无角变形。装饰图设空 alt 或 aria-hidden，按钮可访问名称来自 DOM 文本。无需为“出示”“使用”分别生图：两者用同一个按钮组件与材质，文字区分动作。

没有任何图片应承担点击命中区、实时状态、分类标签、数字或说明文本。效果图不能直接铺成背景再叠透明热点。
