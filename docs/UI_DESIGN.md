# 游戏界面设计标准

适用于游戏本体的浏览器和 Electron 界面。改菜单、弹窗、工具栏或设置页时，先按玩家要完成的动作选择下列模式。游戏设置是页签、分段选择和档案夹弹窗的参考实现。

## 视觉层级与布局

| 场合 | 默认做法 | 项目里的例子 |
| --- | --- | --- |
| 一个明确的主操作 | 同一区域突出一个主按钮，用实金色或主操作贴图。辅助操作用描边按钮 | 开始页的开始游戏，模型配置的保存 |
| 经常使用的辅助入口 | 同类入口集中成一组。角落工具栏优先用一排小图标，给图标可读名称，悬停或聚焦时显示说明 | 开始页的导入、工坊、管理、角色库、设置和退出 |
| 切换整页内容 | 页签保持原位，选中项用文字颜色和底线共同标识。键盘左右方向键可以换页 | 游戏偏好、模型配置、上下文 |
| 在同一处选一种来源或筛选结果 | 用一组等宽分段按钮。按实际选项数排布，允许换行，每个按钮用 `aria-pressed` 表达选中态 | 模型来源有两项，调用角色数量随回合变化 |
| 独立的开关 | 用有名称和开关状态的控件，说明写清何时生效。键盘和点击文字均可操作 | 显示行动提示 |

沿用当前主题的字体、纸面、金属色和分隔线。标题和按钮用主题字族，数字诊断和模型 ID 可用等宽字。间距优先取 4、8、12、16、24、32 px，同组控件的间距小于不同功能组之间的间距。字号、圆角、阴影和间距的取值在[主题变量](../frontend/src/styles/tokens.css)中维护。

按钮的颜色与边框复用 `.btn-primary`、`.btn-ghost` 或同类贴图按钮。组件负责点击区域、内边距和窄屏排布。设置页的按钮和输入框以 44 px 为基准，小图标可放进较大的点击区域。悬停时图标、文字和点击区域持续可见，键盘焦点有独立轮廓。详见[按钮样式](../frontend/src/styles/buttons.css)。

## 弹窗与小窗口

档案夹弹窗从上到下排列标题、页签、可滚动正文、状态反馈和操作栏。正文占用剩余高度并独立滚动。长表单、错误提示或滚动条出现时，关闭和保存仍能点到。桌面端把恢复默认放左侧，取消和保存靠右，主操作在末尾。

底部留白从**贴图可见的内框**量到按钮外缘。设置档案夹外缘到底部按钮的距离通常为 38 px，紧凑布局为 32 px。换用别的贴图时按其内框重新量。宽度不足先让卡片改单列、操作栏按组换行。矮窗口可收短保存按钮的说明，保留完整操作名和正文滚动空间。尺寸与断点见[档案夹样式](../frontend/src/styles/components/platform-ui.css)。

## 切换动效

动效用于交代“选了哪里”和“哪块内容更新了”。点击或按键后立即更新选中状态和可操作内容。动画只负责呈现，连续操作时以最后一次选择为准。

| 交互 | 哪部分动 | 默认参数 |
| --- | --- | --- |
| 悬停、切换选中状态 | 控件自身的字色、边框或底色 | `--motion-feedback`，150 ms |
| 切换页签、表单分支或筛选结果 | 新正文从 50% 不透明度淡入，同时向上归位 4 px。标题栏、页签和底栏保持原位 | `--motion-content`，160 ms |
| 分段按钮切换 | 一条 2 px 的选中底线移到目标格，按钮和标签原地保留。换行后仍按目标格的位置移到位 | `--motion-indicator`，180 ms |

以上过渡统一使用 `--motion-easing`（`ease-out`）。位移只改变绘制位置。避免用动画改变表单高度、滚动位置或点击区域。仅在视图或选择真正改变时播放，后台刷新同一份列表或在输入框打字时保持稳定。

切换动效写在 `prefers-reduced-motion: no-preference` 下。系统开启“减少动态效果”时直接呈现终态，选中底线、焦点和状态文字照常可见。上述时长适用于操作界面，骰子演出和叙事播放可按各自节奏设计。参见[设置组件](../frontend/src/react/components/ModelSettingsPanel.tsx)和[动效变量](../frontend/src/styles/tokens.css)。

## 改完怎么验

- 在本地用 1280、939、640 px 宽度查看真实界面。检查最长标签、鼠标悬停和键盘焦点，确认没有文字竖排、图标消失或点击区域挤压。改到底栏时，再看 390 × 360 的矮窗口。
- 对切换控件连续点两项，再用键盘切一次。核对选中标记、正文和焦点。动态分段用一项、两项和多到换行的样例，确认底线落在实际按钮下。
- 开启系统“减少动态效果”再切一次。内容应立即可用，选中态依然清楚。运行受影响的组件测试并构建前端，从本地单人入口 `/?mode=local` 打开设置，等启动遮罩消失、界面稳定后截图，放在仓库外的任务目录。可复用[设置页浏览器测试](../frontend/e2e/model-settings.spec.ts)。
