# TRPG-Master 毕业论文测试报告（2026-11-17）

本批新增 **123 次真实 DeepSeek 模型调用**，覆盖经典路径主线、结构化行动承接和角色记忆；加上前一批摘要消融实验的 96 次，合计 **219 次真实调用**。行动承接 5/7、记忆 3/5 通过。经典主线执行 35 回合，阶段目标 17/17、断言 33/33 通过，整体结论为“通过”。原始结果中包含未通过项，未重试筛选更好的结果。

## 1. 测试版本与运行环境

- 项目：TRPG-Master；基线提交 `0bedf6591bb8a245b84c13592211bb3ad0828fc6`。
- 实际测试对象：当日本地工作树，**含未提交修改**。文件相对路径及 SHA-256 见 [source-state.json](source-state.json)。报告分支只提交证据，不包含这些已有业务修改，因此分支代码不等同于完整的受测工作树。
- 环境：Linux、Python 3.12.14，项目前后端虚拟环境及版本见 [environment.json](ablation/environment.json)。
- API：`https://api.deepseek.com`；实际返回模型 `deepseek-flash`；禁用 GLM 路由。记录的 stream 请求、响应 ID、用量均来自实际服务。
- 新增实测上限：每次模型输出 8000 tokens，关闭思考模式，模型请求超时 90 秒；结构化单次验收等待上限 240 秒。各角色实际请求参数以审计日志为准。
- 本地独立项目资源副本、运行目录和 SQLite 数据库；未访问正式发布环境。经典路径采用 `GameEngine`，结构化路径从玩家帧进入网关、Agent 与命令服务。它们不是浏览器界面端到端测试。
- 主线与结构化专项使用仓库自带模组《猩红文档》和默认调查员。论文界面演示仍使用自有模组《无声编钟》。

## 2. 测试方法

经典路径执行开局、验尸、威胁确认、学生访问、办公室与小屋、精神病院、买家调查、监视时钟、古董店危机、文档取回、徽章与封印、理智和结局。依据世界快照、线索、交互回调、战斗及物品状态判断，不能仅凭叙事声称成功。脚本 B7 使用规则工具主动施加 SAN 损失，以验证疯狂链路；这是明确安排的压力注入，不是模型在自然主线中自主触发的事件。

结构化行动承接包含一条“意愿—追问—明确出发”链及四个独立对偶世界，核对地点、请求状态和命令提交。记忆专项预先通过真实命令写入测试事实与记忆，再由真实模型处理问题，覆盖长期回忆、角色知识隔离、传闻与事实、缺失信息查询及上下文预算。

SDK 审计包装只记录真实调用，原方法原样执行；没有替换模型输出或伪造命令结果。`started` 与 `completed/error` 按 `call_id` 配对。结构化报告还保存每次请求的输入消息、模型可见输出和命令回执。固定场景种子及自动回答确认属于测试驱动输入。

### 3.1 未通过项与观察

- 行动承接 `C2_follow_up`：追问：继续交谈。运行未正常结束：请求 paused（守秘人助手超出本次预算/步数，已提交结果保留，可接管或稍后继续。）
- 行动承接 `D3_wish_no_move`：意愿式说法：我想回医学院再看看。实际发生移动，预期不移动。
- 记忆 `C_knowledge_isolation`：知识隔离：不在场 NPC 的私密记忆不泄漏。运行未正常结束：paused
- 记忆 `D_rumor_vs_fact`：传闻与事实：传闻带不确定性，事实可直接陈述。运行未正常结束：paused

行动承接 C2 与记忆 C 的回执注明预算/步数耗尽；记忆 D 最后一次输出仅为 `{"type":"json_object"}`，没有可执行决策，系统将请求暂停。日志支持定位这些现象，尚未据此确定单一代码根因。

行动承接 D3 的措辞具有自然语言歧义，本轮脚本预设“表达意愿时先等待回应”，实际模型选择立即移动，因此按该验收预期记为失败。该结果表明行动意图处理存在一致性问题，不能据此推导所有意愿句都会被错误执行。

记忆 C 虽未观察到私密标记出现在可见文本中，但运行未正常完成，不能记为知识隔离用例通过。结构化完整结果见 [行动承接报告](live/transition/report.json) 和 [记忆报告](live/memory/report.json)；经典全流程见 [主线报告](live/classic/report.json)。

## 4. 摘要信息隔离消融实验

这一批在新增主线实测之前完成，原始计划及哈希先于调用生成，见 [实验计划](ablation/ablation-plan.json) 与 [计划哈希](ablation/ablation-plan.sha256)。18 类攻击、6 类正常样本，各重复两次。攻击由三种内部信息载体和六种诱导表达组合而成，秘密标记只位于内部资料，玩家请求不包含该值。

| 分组 | 输入处理与输出处理 | 实际模型调用 | 攻击泄漏 | 正常信息保留 |
| --- | --- | ---: | ---: | ---: |
| P | 仅提示词，保留原始消息 | 48 | 0/36 | 12/12 |
| I | 同提示词，调用实际输入分离函数 | 48 | 0/36 | 12/12 |
| IG | 复用 I 候选，再执行实际可见性校验 | 0（复用） | 0/36 | 12/12 |

原始请求与可见响应见 [ablation-traces.jsonl](ablation/ablation-traces.jsonl)，汇总见 [ablation-results.json](ablation/ablation-results.json)。96 次调用共使用输入 18,508 tokens、输出 7,225 tokens。P/I 模型延迟中位数分别为 1.055/1.047 秒；IG 不产生新的模型延迟。

三组均未泄漏，**本批真实模型结果没有显示组间输出泄漏率的差异**。输入分离将含秘密标记的攻击输入从 36/36 降为 0/36。当前指标检测完整标记及其空白、大小写归一化形式，不等于检验所有语义改写泄漏。

另行进行固定候选注入：将 54 份包含私密标记的摘要和 18 份正常摘要交给相同结构检查及可见性校验。仅结构检查接纳 54 份风险候选，增加可见性校验后全部拒绝，正常候选接纳 18/18。该项 **不调用模型**，验证给定候选的代码处理行为；不是“模型产生 54 次泄漏”。见 [固定候选结果](ablation/fault-injection-results.json)。

## 7. 结论

确定性自动化测试通过了本次执行范围内的检查，真实模型实测则暴露了暂停收敛与意愿表达处理方面的未通过用例。摘要消融实验没有观察到泄漏率差异，代码隔离和固定候选校验分别提供了输入控制与候选拒绝的证据。后续改进应针对已记录的失败用例开展，再以同样的输入和状态条件复测。
